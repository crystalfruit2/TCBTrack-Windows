# Edge-Optimized Multi-Drone Target Tracking via YOLOX
Edge-Optimized Multi-Drone Target Tracking via YOLOX with Exponential History Loss and EMA Feature Filtering

TCBTrack Installation & Troubleshooting Log
This document tracks the specific environment setup and dependency fixes required to run TCBTrack on a Windows machine within a Miniconda environment.

1. Environment Initialization
The project uses a dedicated Miniconda environment to isolate dependencies.

Bash
# Create and activate the environment
conda create -n tcb_env python=3.8
conda activate tcb_env
2. Data Preparation
For the MOT17 dataset, the validation set must be generated by splitting the training data (halving).

Bash
cd <TCBTrack_HOME>/TCB
python tools/generate_val.py
3. Model Weights (The "Baidu Bypass")
Due to Baidu Drive download restrictions, the official mot17.pth.tar was replaced with a compatible ByteTrack "donor brain."

Download: bytetrack_x_mot17.pth.tar from the ByteTrack GitHub Releases.

Directory: Create TCBTrack/TCB/models/.

Rename: Move the file to that folder and rename it to mot17.pth.tar.

4. Dependency Troubleshooting
During the first run, several version conflicts were resolved to satisfy the older academic codebase.

Error 1: Protobuf Descriptor Error
Issue: TypeError: Descriptors cannot be created directly.

Cause: Protobuf 4.x+ is not backwards compatible with older ONNX/Tensorboard versions.

Fix: Downgrade Protobuf.

Bash
pip install "protobuf<4.0.0"
Error 2: NumPy Attribute Error
Issue: AttributeError: module 'numpy' has no attribute 'object'.

Cause: NumPy 1.24+ removed np.object.

Fix: Downgrade NumPy to a compatible version.

Bash
pip install "numpy<1.24"
Error 3: GPU Assertion Error
Issue: AssertionError at assert num_gpu <= torch.cuda.device_count().

Cause: The script requested 1 GPU (-d 1), but the environment only detected a CPU.

Fix: Change the execution command to CPU mode (set -d 0 and remove --fp16).

5. Execution Command
The final verified command to run the tracker on a CPU:

Bash
python tools/track2.py -f exps/example/mot/mot17.py -c models/mot17.pth.tar -b 1 -d 0
